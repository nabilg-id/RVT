# ``av.open(path, metadata_errors="ignore")``, tapi PyAV 19 menghapus parameter

#   TypeError: open() got an unexpected keyword argument 'metadata_errors'

# faster-whisper hanya menyebut ``av>=11`` tanpa batas atas, jadi tidak ada
# versi faster-whisper yang cocok dengan av 19. Pin di sini sampai
# faster-whisper berhenti mengirim parameter tersebut.
